一、交付目标
------------

- Kotlin 原生 Android App，禁止 WebView 套壳。
- Python/FastAPI 数据服务。
- 公开内容同步器、SQLite 索引、校验和 Android assets 导出。
- 可编译 Debug/Release APK。
- README、DOCS、站点分析、功能要求和可恢复任务记录。
- Backend 测试、Android JVM 测试、lint、APK 构建和 CI。
- Linux 主机上的爬虫 systemd 开机续跑。

当前实际限制：

- 新一轮全本同步尚未完成，不能宣称 APK 已包含 30,989 条全本正文。
- Android 真机、TTS 音频、Widget、Edge-TTS 和 AI 端到端验收不在当前无设备环境中完成。
- 正式 Release 签名必须由发布环境提供 keystore 和环境变量。
- 公开同步遵守 robots、同源、限速、重试和访问边界。

二、架构
--------

Android：

- data：Retrofit、Room、FTS、资产导入、TTS、AI 设置和持久化。
- domain：ReadingItem、目录、百科、Repository contract、字形映射和 TTS contract。
- ui：Compose、MVVM、StateFlow、详情阅读、学习图表、笔记和设置。
- di：Hilt 组装。

Backend：

- app/main.py：REST API。
- app/store.py：SQLite items、目录、百科和 HTTP cache。
- app/crawler.py：HTML robots-aware fetcher。
- app/parsers.py：无网络纯解析器。
- app/tongjian_sync.py：公开《资治通鉴》 JSON API 断点同步。
- app/export_android.py：正文、目录、百科资产校验和原子导出。
- tests：API、crawler、parser、sync 回归。

四、同步规范
------------

已确认公开接口：

- GET https://www.dutongjian.com/api/table_of_contents
- GET https://www.dutongjian.com/api/reign?reign_tongjian_id=<公开纪年 ID>

目标数据结构：

- 294 卷。
- 1,405 个纪年节点。
- 30,989 条正文。

默认命令：

    ./scripts/resume_crawler.sh

该命令只续跑，不带 --reset。数据全部放在项目目录：

    service/data/dutongjian.db
    service/data/tongjian-cache/
    service/data/tongjian-progress.json
    service/data/resync-archive-20260803/

新抓取内容不得放在 /tmp。同步器内部的 .tmp 仅是同目录原子写入中间文件。

首次重新清理时才使用：

    PYTHONPATH=service python -m app.tongjian_sync \
      --allow-public-api \
      --reset \
      --database service/data/dutongjian.db \
      --cache-dir service/data/tongjian-cache \
      --checkpoint service/data/tongjian-progress.json \
      --workers 4 \
      --min-interval 0.5 \
      --respect-robots

爬虫规则：

- robots.txt 无法读取时拒绝网络请求。
- 只访问配置 base URL 的公开路径。
- cache 命中不发请求。
- 请求启动受全局间隔控制，worker 数量有界。
- HTTP 429 读取 Retry-After，并共享冷却窗口。
- 每个纪年成功后更新 checkpoint。
- 单个纪年失败不丢失已完成结果；failed_reign_ids 和 last_errors 写入 checkpoint，下一次恢复重试。
- 不通过提高并发绕过站点限流。

五、恢复流程
------------

意外停止或机器重启后：

    cd /mnt/workspace/readgb
    sed -n '1,240p' PROJECT_STATE.md
    git status --short
    ps -eo pid,etime,cmd | rg 'tongjian_sync|readgb-crawler' | rg -v 'rg '
    jq '{total_reigns, completed: (.completed_reign_ids | length), updated_at}' \
      service/data/tongjian-progress.json
    ./scripts/resume_crawler.sh

如果已有同步进程持有 service/data/tongjian-sync.lock，恢复脚本会退出，不启动重复进程。不要删除数据库、cache 或 checkpoint。只有确认需要从头清理时才使用 --reset。

开机服务：

    ./scripts/install_crawler_service.sh

systemd unit 使用 scripts/resume_crawler.sh，失败自动重启，不带 --reset。容器没有 systemd PID 1 时，安装脚本只负责留下 unit 和 enable 链接，宿主机启动后接管。

六、构建和测试
--------------

Backend：

    python3 -m pytest -q service/tests
    python3 -m compileall -q service/app

Android：

    cd android
    ./gradlew testDebugUnitTest
    ./gradlew lintDebug
    ./gradlew assembleDebug
    ./gradlew assembleRelease

CI：

.github/workflows/ci.yml 使用 Python 3.12、JDK 21、SDK 35，执行 Python 覆盖率测试和 Android test/lint/Debug/Release build，并缓存 pip/Gradle。CI 不运行真实网站同步。

2. 在 PROJECT_STATE.md 当前任务清单写目标、路径和恢复方式。
3. 完成项行末加 ✅；未完成项保留未勾选并写明下一步。
4. 测试、同步、部署、数据路径和构建变化追加到同一文件的变更日志。
5. 提交前执行测试、git diff --check，并确认没有把数据库/cache/checkpoint/APK/keystore 加入 Git。
6. 用户要求推送时，提交后确认远端分支和 commit。
